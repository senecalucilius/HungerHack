- hungerhack-logo.png: supplied transparent HungerHack logo

To update the GitHub repository:
1. Open the HungerHack repository on GitHub.
2. Replace the existing index.html with this revised index.html.
3. Upload hungerhack-logo.png to the same repository root (same level as index.html).
4. Commit the changes to the main branch.
5. Wait for Cloudflare deployment to finish, then refresh the website.

Keep both files in the repository root. The logo is referenced as hungerhack-logo.png.
